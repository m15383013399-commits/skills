# Draft Workflow

一、输入顺序

1、先读输出约束
1.1 `AGENTS.md`
1.2 用户补充要求

2、再读交接文件
2.1 `prototype-prd-handoff.md`

3、再读源材料
3.1 项目说明
3.2 原型说明
3.3 原型图和流程图

二、执行步骤

1、先锁定成稿结构
1.1 有项目结构就按项目结构。
1.2 没有就按默认结构写。

2、先读交接文件
2.1 提取页面清单。
2.2 提取已确认规则。
2.3 提取 `本期不做`。
2.4 提取 `待确认`。

3、再和源材料交叉验证
3.1 核页面是否一致。
3.2 核关键交互是否一致。
3.3 核流程和状态是否一致。
3.4 有阻塞性冲突时再追问。

4、开始写正文
4.1 先写页面结构。
4.2 再写交互说明。
4.3 再写字段与规则。
4.4 再写状态说明。
4.5 再写异常与边界。
4.6 最后带上 `本期不做 / 待确认`。

5、最后做漏项检查
5.1 默认值有没有漏。
5.2 联动有没有漏。
5.3 覆盖逻辑有没有漏。
5.4 历史影响有没有漏。
5.5 前后端边界有没有漏。
