# Handoff Contract

`prototype-prd-handoff.md` 是 drafting skill 的第一层解释口径。

使用规则：

1、先读 handoff，再读原始材料。
2、handoff 中的已确认规则默认可直接进入正文。
3、handoff 中的 `待确认` 不要擅自写死。
4、如果 handoff 与原始材料冲突，以原始材料为证据回问用户。
5、如果 handoff 缺失关键模块，优先让用户补澄清，不要硬写。

handoff 至少应包含：

1、页面与功能点清单。
2、已确认业务流程。
3、已确认交互规则。
4、已确认字段与规则。
5、状态与边界。
6、本期不做。
7、待确认。
