# Clarify Question Framework

一、第一轮优先问

1、主业务流程
1.1 用户从哪里进入。
1.2 主流程到哪里结束。
1.3 中间是否有审批、分配、回退、重试。

2、页面关系
2.1 哪些是独立页面。
2.2 哪些是弹窗或抽屉。
2.3 保存后返回哪。
2.4 是否刷新原页面。

3、按钮逻辑
3.1 什么时候可点。
3.2 点完后做什么。
3.3 是否弹确认框。
3.4 是否允许撤销、删除、覆盖。

二、第二轮优先问

1、字段和校验
1.1 哪些必填。
1.2 哪些只读。
1.3 默认值从哪来。
1.4 是否有唯一性、重复性、格式限制。

2、状态和边界
2.1 有哪些状态。
2.2 状态怎么切换。
2.3 失败时怎么提示。
2.4 哪些情况不允许操作。

3、联动和影响范围
3.1 上下级是否联动。
3.2 多字段是否联动。
3.3 切换类型后哪些字段重置。
3.4 改配置后影响当前数据还是历史数据。

三、第三轮优先问

1、前后端边界
1.1 前端先拦还是后端拦。
1.2 后端处理中前端是否展示过程。
1.3 后端拿不到的数据是否不展示。

2、批量处理
2.1 多条数据原值不一致怎么展示。
2.2 混选是否允许。
2.3 批量修改是否覆盖全部。

3、异常路径
3.1 上传失败。
3.2 导出失败。
3.3 搜索无结果。
3.4 周期冲突。
3.5 名称重复。

四、什么时候停止提问

1、主流程已经闭环。
2、关键按钮逻辑已经闭环。
3、状态流转已经闭环。
4、联动和覆盖逻辑已经闭环。
5、剩余问题都可以合理落成 `待确认`。
