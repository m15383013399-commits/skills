# Clarify Workflow

一、输入顺序

1、先读输出约束
1.1 `AGENTS.md`
1.2 用户补充的文档要求

2、再读业务事实
2.1 项目说明
2.2 原型说明
2.3 已对齐规则

3、最后读原型材料
3.1 页面原型
3.2 流程图
3.3 页面截图
3.4 交互稿

二、执行步骤

1、先列页面清单
1.1 主页面单列。
1.2 弹窗单列。
1.3 抽屉单列。
1.4 详情页单列。
1.5 选择器和特殊空状态按独立功能点处理。

2、再画页面关系
2.1 从哪里进入。
2.2 点什么进入。
2.3 保存后回哪里。
2.4 关闭后回哪里。
2.5 是否刷新原页面。

3、先做一轮推演
3.1 按主流程走一遍。
3.2 按异常路径走一遍。
3.3 按失败路径走一遍。
3.4 把走不通、不确定、互相冲突的点记下来。

4、再分批提问
4.1 先问阻塞性问题。
4.2 再问联动和状态问题。
4.3 最后问优化性和展示性问题。

5、每轮回答后重新推演
5.1 看主流程是否闭环。
5.2 看按钮逻辑是否闭环。
5.3 看状态流转是否闭环。
5.4 看上下游联动是否闭环。
5.5 看前后端边界是否闭环。

6、输出交接文件
6.1 用固定模板写。
6.2 只写结论，不写完整对话。
6.3 没法确认的内容保留为 `待确认`。
