# prototype-prd-handoff.md Template

按下面结构输出交接文件：

```md
# PRD Handoff

一、输入来源
1、AGENTS.md / 文档约束
2、项目说明 / 原型说明
3、原型材料

二、文档输出约束
1、语言
2、结构
3、编号
4、禁用表达
5、特殊要求

三、页面与功能点清单
1、页面/弹窗/抽屉/详情页完整列表
2、页面关系

四、已确认业务流程
1、主流程
2、异常流程
3、返回路径

五、已确认交互规则
1、按钮行为
2、切换逻辑
3、弹窗打开与关闭
4、保存、删除、停用、下发后的变化

六、已确认字段与规则
1、默认值
2、必填
3、可编辑性
4、校验
5、联动
6、前后端边界

七、状态与边界
1、状态枚举
2、状态切换条件
3、异常提示
4、历史影响

八、本期不做
1、明确不做项

九、待确认
1、未解决但不阻塞正文的问题

十、成稿要求
1、成稿必须覆盖的重点
2、成稿时不能遗漏的规则
```

要求：

1、只写结论，不写完整问答记录。
2、能落成明确规则的，不写成开放问题。
3、不能确定的保留为 `待确认`。
4、后续 drafting skill 以这份文件作为第一层解释口径。
